# Agents

Each worker has its own image, one-replica Deployment, internal Service and resource budget.
The coordinator owns durable state and human approvals.

- [Research](research/README.md): restricted Oh My Pi web research through Scalekit Exa,
  including dedicated company/person subject research for customer meetings.
- [Contacts](contacts/README.md): company and professional contact enrichment.
- [Meetings](meetings/README.md): transcript-grounded customer notes and issue proposals.

See the [meeting workflow](../docs/meeting-agent.md) for Zoom capture and approved GitHub
publication. Start future workers from `tooling/templates/agent.yaml`.
